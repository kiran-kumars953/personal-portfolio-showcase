# Security Policy

## Reporting a vulnerability

Please do **not** open a public issue for security problems.
Email **kirankumar953863@gmail.com** with the steps to reproduce and the impact. You will get an acknowledgement within 72 hours.

## Secrets

This repository contains no credentials. All keys and passwords are read from environment variables at runtime. If you ever spot something that looks like a real secret, report it using the address above.
